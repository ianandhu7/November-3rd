# Prompt 09: Mobile Responsiveness & Touch Interactions

## Objective
Ensure the museum delivers an intimate, flawless experience on smartphones (iOS Safari, Android Chrome), tablets, and high-DPI desktop screens.

## Responsive Enhancements
- Collapsible bottom navigation bar / floating control hub on mobile.
- Touch-friendly tap targets (minimum 44x44px).
- Smooth horizontal swipe for scrapbook cards and polaroid filmstrips.
- Scaled envelope and letter dimensions for smaller viewports so paper unfolds elegantly without overflowing.
- Fluid typography utilizing `clamp()` scaling.
